## 1. 设计语言：双寄存器

| 寄存器 | 范围 | 对标 | 原则 |
|--------|------|------|------|
| Product 寄存器 | 工具栏本体、设置页 | Linear / Vercel | 扁平克制、细边框、输入法用户熟悉感；不喧宾夺主 |
| Brand 寄存器 | 宠物本体、工坊 UI | VPet + Bongo Cat | 状态驱动动画、独特性、陪伴感；宠物是情绪出口 |

工坊界面套 Wallpaper Engine 三 Tab 范式：**已安装 / 发现 / 工坊**，内置浏览订阅不跳出应用。

## 4. 宠物与工具栏融合范式

核心原则：**工具栏 = 控制信道，宠物 = 状态信道，互不抢焦**。

### 4.1 栖木式吸附
宠物趴工具栏上沿（边线作栖木），视觉上"栖息"而非"拼接"。

### 4.2 状态共生动画（四态联动）

| 输入法状态 | 宠物表现 |
|------------|----------|
| 中文模式 | 打小键盘 |
| 英文模式 | 打盹偷瞄 |
| 全/半角切换 | 体型/影子变化 |
| 简/繁切换 | 换装 |
| 打字中 | 敲键盘动画 |

### 4.3 回巢锚点
宠物闲逛（非 MVP，预留）后自动跳回工具栏位置。

### 4.4 碰撞规避
宠物动画不遮挡 6 按钮热区；点击穿透走 ULW alpha。

### 4.5 闲置态
VPet 式挂边窥视（间隔出现，非持续动画，省电）。

## 5. 图标系统（锁定）

- **图标库 = Lucide**（ISC 许可可商用）：24×24 统一 2px 描边 + currentColor，与扁平细边框同构。
- 尺寸规范：16px（行内）/ 20px（按钮内）/ 24px（独立图标），全项目一致。
- 实现：path data 嵌入 Rust/tiny-skia 绘制（约 20 枚）。
- **全项目禁止 emoji 作功能图标（P0）**；桌宠动画素材（精灵帧 PNG）不属图标范畴。

## 6. 界面清单（MVP）

| 界面 | 要点 |
|------|------|
| 工具栏 + 宠物复合窗口 | 栖木式；宠物区右侧；深色默认皮肤 |

| 默认宠物 | 立品质标杆：完整动画集（闲置/打字/中英/简繁/全半角） |
