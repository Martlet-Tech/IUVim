# PRD v1.0 · iuvim 桌宠挂件 + Steam 创意工坊

> 生成日期：2026-08-29
> 状态：待用户确认（Phase 1 门禁）
> 基于：Phase 0 需求澄清 + PM/架构师/设计师三方调研

---

## 1. 产品定义

- **一句话描述**：iuvim 输入法浮动工具栏升级为「工具栏本体 + 可互动桌面宠物挂件」，免费上架 Steam，通过创意工坊让玩家用 Lua 脚本 + 2D 精灵帧素材自行扩展宠物。
- **目标用户**：16-30 岁二次元/桌宠爱好者（学生、年轻白领、独居/远程办公求陪伴、桌面美化玩家）、直播录屏 up 主；创作者 = 像素画师/动画爱好者、会 Lua 的玩家、Vtuber 相关内容人。
- **核心问题**：市面上没有「输入法本体 + 桌宠」产品——搜狗桌面萌宠只证明需求存在（皮肤级互动弱、启动 3-5 分钟、广告驱动封闭）；3D/WPF 桌宠普遍高 CPU/GPU 占用被集中吐槽；iuvim 用 Rust + tiny-skia 天然解决性能痛点，且开放无广告。

## 2. 竞品矩阵（调研结论）

| 竞品 | 定位/定价 | 优劣 | 对 iuvim 的启示 |
|------|-----------|------|-----------------|

| Desktop Mate | 本体免费+角色 DLC 2200 日元 | 仅 60% 好评——本体空、DLC 付费墙、GPU 占用 68%、需常驻 Steam | 反面教材：本体必须立得住，付费墙破坏口碑 |

## 3. 市场空白（三句话）

1. **无「输入法本体 + 桌宠」产品**：宠物挂工具栏、随中英/全半角/标点/简繁/打字状态实时反应 = 功能 + 情绪双价值，无人做。
2. **性能是共性痛点**：3D/WPF 被集中吐槽；Rust + tiny-skia 是差异化王牌。
3. **搜狗封闭广告 vs iuvim 开放无广告工坊**：生态路线是 Wallpaper Engine 式护城河。

## 4. 用户画像

- **主用户**：16-30 岁二次元/桌宠爱好者、学生及年轻白领、独居/远程办公求陪伴、桌面美化玩家；直播录屏 up 主（Bongo Cat 标配人群）。
- **创作者**：像素画师/动画爱好者、会 Lua 或简单脚本的玩家、Vtuber 相关内容人；动机 = 作品展示 + 社区声望。

## 5. MVP 范围（锁定——不在此列表的功能一律不做）

| 优先级 | 功能 | 验收标准摘要 | RICE |
|--------|------|-------------|------|
| P0 | 宠物挂工具栏 + 随输入状态反应 | 宠物吸附工具栏（栖木式），中英/全半角/标点/简繁切换与打字时有对应动画 | 10 |
| P0 | 基础互动 + 1 只默认宠物 | 点击互动、拖拽、闲置动画；默认宠立品质标杆 | 5.4 |
| P0 | 工坊订阅加载（Lua 沙箱 + 精灵帧） | Steam 在线可浏览/订阅/下载 mod，离线已下载 mod 继续可用 | 3.8 |
| P1 | 工坊上传 + 模板文档 | 创作者可提交 mod，官方模板降门槛 | 1.4 |
| Backlog | 多宠同屏、语音互动 | 生态成熟后评估 | 0.4 |

## 6. 明确不做（Out-of-Scope — 锁定）

| 不做的功能 | 原因 | 何时考虑 |
|------------|------|----------|
| 付费 Mod / 内购 DLC | 天际付费 Mod 3 天被骂撤的教训；工坊一律免费保口碑 | 不做 |
| 独立进程隔离 mod 脚本 | 实现优先策略，线程内跑 + 兜底三件套足够 | mod 生态起来后 |
| 3D/骨骼动画宠物 | 制作门槛高、性能重，与 2D 精灵帧路线冲突 | 用户反馈后 |
| 宠物脱离工具栏独立放置 | 需第二消息泵 + 双窗同步，MVP 不划算 | v2.0 评估 |
| macOS/Linux 支持 | Steam 允许仅 Windows，无必要 | 有明确需求后 |
| 多宠同屏 | Backlog | v2.0 |
| 全屏游戏内显示 | 与 Wallpaper Engine 学习：全屏自动暂停降耗 | MVP 内置暂停策略即可 |

## 7. 商业模式（锁定）

- **本体免费**上架 Steam（Software 免费档，$100 Steam Direct 一次性费用，累计收入 $1000 返还）。
- **创意工坊免费 Mod**：开放格式（Lua 逻辑 + PNG 精灵帧表，参照 OpenPets/Shimeji），官方模板 + 创作者专区 + 赛事激励，默认宠立品质标杆。
- **无广告**：区别于搜狗桌面萌宠的广告驱动模式。

## 8. 创意工坊生态策略

1. 工坊内容一律免费（禁付费 Mod）。
2. Lua 沙箱隔离（Luau 特性，Roblox 同款设计）。
3. Mod 版本控制（随游戏/应用版本失效机制）。
4. 内置浏览订阅，不跳出应用（学 Wallpaper Engine 三 Tab：已安装/发现/工坊）。
5. 版权：UGC 条款 + 举报机制；上传者担责（引用 Steam UGC 条款）。
6. 模组恶意软件防护：脚本指令上限 + 沙箱 + 审核举报双轨。

## 9. 成功指标（KPI）

- MVP 期：Steam 商店页上线、1000 次安装、50 个创意工坊 mod（含官方模板产物）。
- 稳定期：月活 5000、工坊 mod 增速 >10/周、平均会话时长（宠物在线时长）提升。

## 10. 风险登记

| 风险 | 处置（已拍板） |
|------|----------------|
| Workshop 依赖 Steam 客户端运行，输入法用户不一定常开 Steam | 已下载 mod 本地持久化，离线继续可用；Steam 在线才同步订阅/更新（Wallpaper Engine 模式） |
| mod 脚本异常波及 daemon | 线程内跑 Lua + 指令上限 + panic 捕获（实现优先，不做进程隔离） |
| Steam 不执行 UGC 版权审核 | UGC 条款 + 举报机制 + 工坊一律免费 |
