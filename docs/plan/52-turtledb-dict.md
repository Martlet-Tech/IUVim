# 52 · 水豚服专有词条词库

状态：**调研完成，暂缓**——有前置事项优先，见 §4。

## 1. 需求

玩家在魔兽私服「水豚乐园」（Turtle WoW，原乌龟服亚服合服而来），有大量自定义词条（自定义物品/NPC/地名/任务名），QQ/搜狗等输入法均无覆盖。希望给 iuv 做一个水豚服专有词库。**不改代码**。

## 2. 调查结论

- 数据源现成：**TurtleDB**（<https://db.turtletail.net/>），乌龟服中文数据库站，明确包含乌龟服独有内容，可按分类翻页抓取，无需逆向客户端。
- 备选数据源（TurtleDB 不可用时）：
  - 客户端补丁挖掘（自定义 MPQ → DBC/DB2，社区开源工具如 wow.export 可解包）；
  - 游戏内 addon dump / 论坛攻略手动汇总（校对用）。
- 接入路径（零代码改动，词库链已支持）：
  1. 词条行格式 = Rime 风格 `.dict.yaml`：`词<TAB>带空格拼音<TAB>权重`（`iuv-data/src/compile.rs` parse_file）；
  2. 产物 `turtledb.dict.yaml` 丢进 `data\rime-frost\cn_dicts\`，安装链 Ensure-Imedic 自动 glob 合并、dictc 编译为 `iuv.imedic`（`scripts/iuv-common.ps1`）；
  3. 简拼键（如 `yghy`→永歌荒野）由 dictc 编译期自动生成，无需额外处理。

## 3. 拟定流程（开工时照此做）

抓取/转换脚本放 iuvim 仓库外的独立目录（不进 git 仓库）：

1. 爬 TurtleDB 自定义内容中文词条（物品/NPC/地名/任务名）；
2. 与原版 1.12 词表求差集，只留新增词；剔除纯英文/数字条目；
3. Python `pypinyin` 自动注音（专名多音字可能有少量错标，人工扫一遍）；
4. 给较高权重，保证排通用词之前；
5. 重跑词库编译链 + 部署 `%LOCALAPPDATA%\iuv\iuv.imedic`，真机验证候选。
