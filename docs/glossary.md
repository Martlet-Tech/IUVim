# 术语表（说人话版）

> 给不熟悉输入法工程的人看的。遇到看不懂的词先来这里查。
> 配合 `docs/closed/15-input-matching.md`（砍尾巴机制设计）阅读。

## 拼音输入的基础概念

| 术语 | 说人话 | 例子 |
|---|---|---|
| **全拼** | 一个字/词用完整拼音打出来 | 打 `beishui` 得到"背水" |
| **简拼** | 只打每个音节的**第一个字母** | 打 `bsyz` 得到"背水一战"（b=背 s=水 y=一 z=战） |
| **音节** | 拼音的最小发音单位，一个字一个音节 | `beishui` 拆成 `bei` + `shui` 两个音节 |
| **码（code）** | 词条在词库里的"钥匙串"，就是它的拼音连写 | 词条"背水一战"的码是 `beishuiyizhan` |
| **简拼码** | 每个音节取首字母拼起来的短码 | "背水一战"的简拼码是 `bsyz` |

## 词库（字典）相关

| 术语 | 说人话 | 例子 |
|---|---|---|
| **词条** | 词库里的一条记录：一个词 + 它的拼音 + 一个权重数字 | 词条：`背水一战 / bei shui yi zhan / 权重 100` |
| **权重** | 这个词"多常用"的数字，越大越常用，候选排越前 | 权重 100000 的"的"永远排第一 |
| **exact（精确查询）** | 按码**完全相等**找词 | 输入 `nihao`，exact 找到所有码正好是 `nihao` 的词 |
| **prefix（前缀查询）** | 找所有码**以某串开头**的词 | 输入 `ni`，prefix 能找到"你好"(nihao)、"你行"(nixing)… |

## 输入过程相关

| 术语 | 说人话 | 例子 |
|---|---|---|
| **切分（segment）** | 把打进去的字母串拆成一段段音节 | `nihao` → `[ni, hao]`；`bsyzsgcy` → `[b,s,y,z,s,g,c,y]` |
| **强制分音节** | 用 `'` 告诉输入法"这里必须切开"，解决歧义 | 打 `xi'an`（西安），不打会变成 `xian`（先） |
| **预编辑（composition）** | 还没上屏、在输入框里跟着光标显示的那串字 | 打 `nihao` 时显示"你好"或 `ni'hao` 的那部分 |
| **上屏（commit）** | 确认，把预编辑的内容真正写进文档 | 按空格/数字后"你好"进正文 |
| **候选（candidate）** | 输入法猜你想要的词的列表，一排排的 | 打 `nihao` 出现 1.你好 2.泥嚎 3.拟好… |
| **句子候选** | 引擎把多个音节拼成一句完整的话，作首选 | 打 `nihao` 首选直接是"你好" |
| **会话（session）** | 一次完整的输入过程：打第一个字母开始，上屏/取消结束 | 打 `nihao` → 选词上屏，这次会话结束 |
| **透明模式** | 词库加载失败时的保命模式：输入法假装不存在，所有按键直接放行 | 词库文件被删，还能正常打字，只是没有候选 |

## 砍尾巴机制（本项目的核心匹配逻辑）

| 术语 | 说人话 | 例子 |
|---|---|---|
| **砍尾巴** | 输入的一串码整体匹配不上时，从**末尾**一节一节地砍掉，砍到能匹配为止；越长的匹配越优先 | `bsyzsgcy` 整串没词 → 砍成 `bsyzsgc` 没有 → … → `bsyz` 有了 → 出"背水一战" |
| **匹配长度** | 砍尾巴后，输入串里被"消耗"掉了几节（几个音节/字母） | `bsyzsgcy` 命中 `bsyz`，匹配长度 4，剩 `sgcy` |
| **续接** | 选了一个词后，剩下没匹配完的输入串继续走一遍匹配流程 | 选"背水一战"上屏后，剩 `sgcy` 自动接着匹配 |
| **混合段** | 一段可以是全拼（`ni`）也可以是简拼（`h`），引擎按"一段=一个音节"统一理解 | 打 `h'a` → `h`(简拼=好) + `a`(全拼=啊) → "好啊" |

## 排序相关（M2 已落地，实际机制与早期构想不同）

| 术语 | 说人话 |
|---|---|
| **滞回排序** | 早期构想：两个候选词频接近时顺序锁死不动；要"明显"更常用才换位。**已废弃**（2026-08-14）：滞回只防短期抖动、治不了长期漂移，M2 改为用户主动调权 |
| **钉选** | 早期构想：用户手动把某个候选固定到第一位。**不做**（2026-08-14 用户决策）：Shift+←/→ 手动排序已满足 |
| **用户词库/学习** | 把你选过的词记下来，以后优先。M2 已落地：Shift+←/→ 调权（绝对值覆盖）+ 自造词 + Shift+Delete 隐藏（见 18-m2-user-dict.md） |

## 工程结构相关

| 术语 | 说人话 |
|---|---|
| **iuv-data** | 词库的加工厂和仓库：把 yaml 词库编译成二进制、提供查询 |
| **iuv-core** | 大脑：切分、匹配、生成候选、管输入过程（跨平台纯 Rust，不碰 Windows） |
| **iuv-tsf** | 手脚：和 Windows 输入法框架（TSF）打交道，把大脑的结果显示出来 |
| **iuv-repl** | 命令行玩具：不开输入法也能在终端里试大脑的效果 |
| **TSF** | Windows 的输入法框架，应用和输入法之间的中间人 |
| **dictc** | 词库编译器，把文本词库变成程序能快速读的二进制文件 |
